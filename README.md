## 从想法到第一个作品

1. **明确一个小任务**：例如个人作品集、读书记录或一个简单计算器，写清使用者和完成标准。
2. **只选一款主力编程工具**：从上面的编程工具开始，在同一个小项目中验证它是否适合自己。
3. **先跑通本地闭环**：安装运行环境，启动项目，完成一个能操作的页面，再逐步增加功能。
4. **按需接入后端**：需要账号或保存数据时，再考虑数据库、认证与存储。
5. **部署并验证**：用真实浏览器检查手机布局、错误反馈和主要交互，把反馈记入下一轮改进。

## 如何选择

先比较实际任务表现、代码可读性、数据处理方式和长期使用成本，再决定是否采用。
这里不维护容易过期的价格、模型名单和安装命令，最新要求请以各工具官方说明为准。
